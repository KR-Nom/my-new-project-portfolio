위 소스 경로는 확인한 로컬 원본의 위치입니다. 전체 교육용 템플릿과 고정 인증 설정은 이 공개 저장소에 포함하지 않았습니다.

## 확인한 실행

- Vue 사본에서 `npm ci`, `npm run build` 통과. 번들 크기 경고가 있었습니다.
- 브라우저에서 랜딩·심사 화면이 렌더되었고 페이지 오류, 이미지 누락, 가로 넘침이 없었습니다.
- 이용 방법 링크의 `#steps` 이동을 확인했습니다.
- 심사 화면은 로컬 UI 미리보기 역할값으로 열었습니다. 실제 인증이나 심사 API·DB 연동을 검증한 캡처가 아닙니다.

심사 화면 자체에 API 준비 중임이 표시되어 있으며 수치·목록은 자리표시자입니다. 원본 백엔드는 강의·수강·결제 교육 템플릿을 포함하고, 확인된 Kafka 이벤트는 `payment.completed`, AI 서비스는 규칙 기반 강의 추천입니다. 목표로 한 AI 서류 검수 전체가 구현된 것처럼 제시하지 않습니다.

전체 백엔드 실행에는 README에 기재된 인증·Gateway 이미지인 `infra-images.tar`가 필요하지만 로컬 MSA 폴더에서 확인하지 못했습니다. 이번 검증 범위는 프론트엔드의 빌드·화면 동작입니다.

신청 저장과 AI 검수를 분리하려던 이유 및 본인의 담당 범위는 [GOLABA 설계 요약](../README.md)에 정리했습니다. 랜딩의 사업 이미지·문구·지원 금액은 원본 실습 화면이며 현재 모집 정보로 보장하지 않습니다.
