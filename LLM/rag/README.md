# PDF 문서 기반 RAG

PDF에서 필요한 내용을 검색해 LLM의 답변 문맥에 전달하는 교육 실습입니다. 원본 구현은 [practice_0.ipynb](./practice_0.ipynb)에서 확인할 수 있습니다.

## 문제와 구성

긴 문서의 내용을 모델의 내부 지식만으로 답하게 하면 문서에 실제로 적힌 설명을 반영했는지 판단하기 어렵습니다. PDF 추출문을 작은 단위로 나누고 질문과 의미적으로 가까운 내용만 답변 생성에 전달했습니다.

| 단계 | 구성 |
|---|---|
| 문서 추출 | pypdf `PdfReader` |
| 청크 분할 | 최대 500자, 중첩 50자 |
| 임베딩 | `text-embedding-3-small` |
| 검색 | FAISS 유사 검색, 기본 top-k 3 |
| 답변 | `gpt-4o`, temperature 0.3 |

기존 로컬 실행 기록에서는 Attention Is All You Need 논문의 추출문 39,611자가 89개 청크로 저장되었습니다. 이는 해당 PDF를 대상으로 한 처리 규모이며 검색 정확도나 답변 정확도 지표가 아닙니다. 검색 관련성과 답변의 근거 충실도는 따로 점검해야 합니다.

## 실행

Python 가상환경에서 `pip install -r requirements.txt`로 의존성을 설치하고, `OPENAI_API_KEY`를 환경변수 또는 Git에 포함되지 않는 로컬 `.env`로 설정합니다. 노트북과 같은 폴더에 사용할 PDF를 `paper-attention.pdf`라는 이름으로 두고 위에서 아래로 실행합니다. 다른 PDF를 쓸 때는 질문 목록도 문서에 맞게 바꿉니다.

논문 원본 PDF는 배포하지 않습니다. 예제 논문은 [arXiv의 저자 공개본](https://arxiv.org/abs/1706.03762)에서 확인할 수 있습니다. 공개 노트북의 실행 출력은 비워 두었으며 이번 공개 작업에서 API를 다시 호출하지 않았습니다.
