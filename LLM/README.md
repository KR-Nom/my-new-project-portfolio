# LLM 파이프라인과 에이전트 실습

문서 검색과 생성, 발주 검토 에이전트를 통해 입력 데이터·결정적인 계산·자연어 설명의 역할을 나눈 학습 결과물입니다.

- [PDF RAG](./rag/README.md): pypdf 추출 → 청크 분할 → 임베딩 → FAISS 검색 → 문맥 기반 답변
- [Order Balance](./order-balance/README.md): 판매·재고·발주·예산의 4-agent 실행판과 5개 역할 설계 요약

노트북은 교육 실습을 바탕으로 구성했습니다. 공개본에서는 API 응답 전문, 논문 추출문, 로컬 경로와 실행 식별자가 포함된 출력 및 실행 메타데이터를 제거했습니다. 원본 교육 PDF·DOCX, API 키, 가상환경과 패키지 캐시는 포함하지 않습니다. 실행에는 사용자가 직접 설정한 API 키가 필요하며 사용료가 발생할 수 있습니다.
