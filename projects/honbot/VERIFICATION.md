# HONBOT 실행 검증 · 2026-09-28

## 환경

- macOS arm64 / Python 3.11.15 / FastAPI / SQLite
- 워크스페이스의 기존 `outputs/portfolio-runtime/public-models/.venv` 사용
- 실제 모델: `mlx-community/Qwen3-1.7B-4bit`, 로컬 MLX OpenAI 호환 API
- 외부 유료 API 호출 없이 로컬 모델을 연결

## API·저장·오류 처리

`python -m unittest discover -s tests -v`: **11개 통과**.

| 검증 | 결과 |
|---|---|
| 질문 → 근거 문맥 → 답변 저장 → 북마크·이해도 → 복습·집계 | 통과 |
| 완료 요청의 같은 ID 재시도 | 같은 질문 반환, 중복 저장 없음 |
| 처리 중 같은 ID 동시 요청 | 409, 모델 함수 호출 1회 |
| 같은 ID를 다른 질문에 재사용 | 409 |
| 모델 시간 초과 → 같은 ID 재시도 | 오류를 답변으로 저장하지 않고 정상 복구 |
| 다른 브라우저의 질문·북마크·부모 질문·내보내기 접근 | 차단 |
| 앱 재시작 후 질문·쿠키 소유권 유지 | 통과 |
| 재시작 시 중단된 pending 요청 복구 | failed로 변경 후 재시도 가능 |
| 빈 질문·범위 밖 시점·잘못된 요청 ID | 422 |
| 0·15·30·60초의 문맥 선택 및 마지막 구간 집계 | 통과 |
| 모델 오류 스키마·HTTP 시간 초과 | 502·504, 내부 응답·키 미노출 |
| MP4 Range 요청·자막·포스터 | 206 및 정상 파일 응답 |

## 실제 모델·미디어 확인

60.046초짜리 MP4의 H.264 영상과 AAC 음성 트랙을 확인했습니다. 한국어 내레이션은 무음이 아니며 강의 구간 4개에 대응합니다. 브라우저에서 재생·구간 이동이 가능합니다. 인코딩에 따른 종료 시점 차이는 질문 전송 시 명세의 60초로 제한합니다.

브라우저에서 **31초**에 `x가 2일 때 접선의 기울기가 왜 4인가요?`를 제출했습니다. 로컬 모델이 `f′(x)=2x`, `f′(2)=4`를 설명하고 출처 시점을 반환했습니다. SQLite에 `openai_compatible`, 답변, 31초 시점, 근거 3개, 북마크, 이해도 의견이 실제 저장됐습니다. 이 단일 요청의 측정 응답 시간은 1,488ms이며 일반적인 성능 보장이나 여러 요청의 평균값이 아닙니다.

후속 질문인 `미분계수와 도함수는 어떻게 다른가요?`에서도 실제 모델이 특정 점의 값과 함수의 차이를 설명했습니다. 새로고침 후 질문·북마크·이해도 의견이 유지되고 질문의 31초 시점으로 돌아가는 것을 확인했습니다.

## 브라우저 흐름

- 실제 질문 2건 → 근거 시점 이동 → 북마크 → 이해도·의견 → 복습·집계 → JSON 내보내기 연결 확인
- 질문 요청에 일회성 503 오류를 주입해 입력 유지·버튼 재활성·같은 요청 ID 재시도 확인. 재시도는 실제 모델로 처리되어 두 번째 질문이 저장됐습니다.
- 영상 종료 시각 60.046초의 질문을 명세 범위인 60초로 전송하는 것을 확인했습니다.
- 390px 화면의 문서 너비 390px, 영상·답변 패널 366px, 질문 입력 332px로 가로 넘침 없음
- agent-browser에 기록된 브라우저 예외 없음
- 실제 실행 캡처: [데스크톱](docs/screen.png), [모바일](docs/screen-mobile.png)

## 해석 범위

API 테스트의 오류·동시성 검증은 통제된 provider를 사용합니다. 실제 모델 연결은 별도 브라우저 흐름으로 확인했습니다. 몇 개의 미적분 예시가 정답률 평가를 대신하지 않습니다. 단일 worker의 로컬 실행을 검증했으며 운영 인증·분산 처리·실시간 영상 인식은 구현 범위가 아닙니다.
