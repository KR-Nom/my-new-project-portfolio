# HONBOT — 영상 챗봇의 요청과 응답 연결

영상 챗봇에서 ChatGPT API 연동을 학습하고, AI의 응답을 서비스 화면에 연결한 경험을 정리했습니다. 이 디렉터리는 당시 경험과 이번 포트폴리오 디자인의 범위를 설명하는 자료입니다.

[Figma 포트폴리오](https://www.figma.com/slides/BtEeOASUuWzEkWpycXmhEb) · [전체 프로젝트](../../README.md)

## 확인된 경험과 역할

사용자가 제공한 설명은 다음과 같습니다.

> HONBOT 영상 챗봇에서 ChatGPT API 연동을 학습하며 AI 기능을 서비스에 연결하는 방식을 익혔습니다.

확인된 범위는 **영상 챗봇, ChatGPT API 연동 학습, 질문 요청과 모델 응답을 서비스에 연결하는 경험**입니다. 당시 프론트엔드·백엔드 프레임워크, DB, 영상 전송 방식, STT·TTS 사용 여부와 구체적인 팀별 역할은 확인되지 않았습니다. 다른 프로젝트에서 사용한 Spring Boot·PostgreSQL 등의 기술을 HONBOT의 스택으로 연결하지 않았습니다.

## 이번 Figma 발전 범위

영상과 대화가 한 화면에서 이어지도록 대표 화면을 재구성합니다.

1. 큰 영상 영역과 대화 기록을 함께 배치해 질문의 맥락을 유지합니다.
2. 질문 입력, 응답 대기, 답변 확인 상태가 구분되도록 구성합니다.
3. `대화 시작 → 질문 입력 → 모델 응답 → 대화 이어가기` 흐름을 보여줍니다.

이는 사용자의 초기 경험을 바탕으로 이번에 발전시킨 **UI 디자인**입니다. 당시 운영 화면을 복원했다거나 새로운 영상·음성·AI 서버를 실제 구현·검증했다는 의미는 아닙니다. 화면에 표현한 상태와 과거에 확인된 API 연동 경험을 구분합니다.

## 원본 자료 확인 상태

현재 작업 폴더의 파일명·텍스트·프로젝트 문서 조사에서는 HONBOT 원본 코드와 영상, 원본 실행 화면을 찾지 못했습니다. 사용자가 당시 흐름을 담은 `Untitled` Figma가 있다고 설명했으나, 해당 파일의 URL과 내용은 아직 확인하지 못했습니다.

이전에 만든 [HONBOT·자율주행 통합 UI](../ai-experience/)도 포트폴리오용 구성 예시입니다. 과거 구현이나 운영 성과의 증거로 사용하지 않습니다. 이 디렉터리에 실행 코드·API 키·대화 원본은 포함하지 않았습니다.
