# AI 서비스 운영 화면 설계

에이전트 실행 기록을 출발점으로 요청, 토큰 사용량, 지연, 오류 분석을 연결하는 운영 UI를 설계했습니다.

- 실행별 모델 호출과 토큰 사용량을 확인합니다.
- 긴 요청과 반복 실패를 분리해 조사하는 흐름을 제안합니다.
- 로그 분석이 제시한 원인 후보는 담당자가 원래 기록과 대조하도록 구성했습니다.

[운영 화면 설계](./index.html) · [기반 실행 기록](../../LLM/order-balance/)

현재 결과물은 확장 설계이며 자동 이상 탐지나 장애 복구 시스템이 운영 중이라는 의미는 아닙니다. 저장된 에이전트 측정값과 향후 제안은 구분해 표시했습니다.
