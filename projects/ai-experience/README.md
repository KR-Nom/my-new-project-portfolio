# HONBOT · 자율주행 경험

HONBOT의 ChatGPT API 연동 학습과 자율주행 프로젝트의 TensorFlow CNN 학습, 데이터 재수집·증강 경험을 정리했습니다.

[대표 화면 구성](./index.html)은 이 포트폴리오를 위해 새로 디자인한 UI입니다. 이전 프로젝트의 실행 화면 또는 운영 성과로 제시한 것은 아닙니다. 원본 앱과 학습 코드가 이 폴더에 포함되어 있지는 않습니다.

직접 확인할 수 있는 별도의 CNN 팀 실습 코드와 결과는 [Fashion-MNIST 딥러닝 실습](https://github.com/KR-Nom/skala-python-deep-learning)에 있습니다.
