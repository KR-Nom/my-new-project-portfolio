# ToonVoice — 웹툰 보이스 스튜디오

웹툰의 컷·대사·화자·목소리 설정을 한 화면에서 검토하는 음성 제작 UI 프로토타입입니다.

## 문제와 화면 설계

1. 말풍선 대사를 옮기고 화자를 나누는 반복 작업 → 컷과 대사 편집을 나란히 배치합니다.
2. 캐릭터의 목소리가 장면마다 달라지는 문제 → 캐릭터별 기본 목소리와 대사별 감정·속도를 분리합니다.
3. 문장 사이 흐름 확인 → 미리듣기·쉼 조절·이어 듣기 영역을 구성합니다.

[대표 편집 화면](./index.html)을 내려받아 브라우저에서 열 수 있습니다. [UI 원본](../../portfolio/project-webtoon.mjs)과 [스타일](../../portfolio/webtoon.css)도 제공합니다.

현재 결과물은 정적 화면 설계입니다. OCR, 음성 합성, 음성 내보내기 엔진은 연결하지 않았습니다. 화면의 대사와 웹툰 컷은 이 프로토타입을 위해 만든 예시입니다.
