# 장현진 포트폴리오

대표 화면, Pain Point, Solution, 담당 범위와 프로젝트 링크를 담은 16:9 HTML 포트폴리오입니다.

- [포트폴리오 HTML](./index.html): 파일을 내려받아 브라우저에서 엽니다.
- 상단 **PDF로 저장** 버튼으로 인쇄합니다. 배경 그래픽을 켜고 머리글·바닥글은 끕니다.
- 문장을 직접 편집하고 **편집본 저장**으로 이미지까지 포함한 단일 HTML을 저장할 수 있습니다.
- 프로젝트별 GitHub 링크와 마지막 장의 프로젝트 디렉터리를 제공합니다.

## 다시 만들기

별도 패키지 설치 없이 Node.js로 실행합니다.

```bash
node portfolio/build.mjs
```

`content.mjs`는 슬라이드 레이아웃, `projects-*.mjs`는 프로젝트 내용, `project-links.mjs`는 링크를 관리합니다. `assets.json`은 원자료 경로와 공개용 이미지 파일을 연결합니다.

실제 실행 화면과 저장된 측정값에는 근거와 조건을 표시했습니다. 새로 디자인한 화면은 UI 설계로 구분했습니다. 웹툰 예시 이미지는 AI로 생성한 창작 이미지이며 프롬프트는 `webtoon-image-prompt.txt`에 있습니다.
