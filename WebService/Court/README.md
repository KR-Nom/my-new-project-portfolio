# CourtCast

야외 코트의 현장 제보와 예보를 구분해 보여주고, 가까운 코트를 비교하는 서비스의 화면 자료입니다.

## 화면 갤러리

[index.html](index.html)을 브라우저에서 열면 세 가지 사용 흐름을 볼 수 있습니다. 이미지 파일만 사용하는 정적 페이지이므로 설치나 API 키가 필요하지 않습니다.

| 화면 | 보여주는 흐름 |
| --- | --- |
| [현장 제보](screenshots/image3.png) | 현재 코트의 비 여부를 한 번에 제보 |
| [주변 코트 탐색](screenshots/image4.png) | 가까운 코트 5곳과 현장 제보·예보 출처 비교 |
| [즐겨찾기](screenshots/image8.png) | 자주 가는 코트의 상태와 알림 규칙 확인 |

## 자료 범위

- 기존 제품·서비스 소개 자료에 포함된 화면을 원본 비율로 정리했습니다.
- 기상 상태와 예보는 **합성 데모 데이터**이며 실시간 정보가 아닙니다.
- 이 폴더에는 실행 가능한 원본 앱 소스가 없으며, 갤러리는 화면 자료를 소개하는 페이지입니다.
- 이미지 안의 제보·탐색·즐겨찾기 버튼은 갤러리에서 동작하지 않습니다. 각 이미지를 누르면 원본 크기로 볼 수 있습니다.
- 지도 API 연동은 후속 계획으로 구분합니다.

```text
Court/
  README.md
  index.html
  screenshots/
    image3.png
    image4.png
    image8.png
```
